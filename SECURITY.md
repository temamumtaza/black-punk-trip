# Kebijakan keamanan

Jika menemukan kerentanan yang dapat mengekspos akun, data trip, bukti pembayaran, atau melewati RLS, jangan membuat issue publik. Laporkan secara privat kepada pemilik repository melalui profil GitHub [temamumtaza](https://github.com/temamumtaza) dengan langkah reproduksi minimal dan tanpa data pengguna nyata.

Mohon sertakan dampak, route atau komponen terdampak, dan bukti konseptual yang aman. Jangan membagikan token, password, signed URL aktif, service-role key, atau screenshot data sensitif.

Target awal respons adalah konfirmasi penerimaan. Perbaikan akan diprioritaskan berdasarkan dampak dan kemudahan eksploitasi.
